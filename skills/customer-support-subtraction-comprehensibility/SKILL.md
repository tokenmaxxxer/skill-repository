# Subtraction / comprehensibility decision rules

Axis: subtraction-comprehensibility (amendment 4). Academic layer: people
systematically default to additive changes and overlook subtractive ones
even when subtraction is the better fix — Adams, Converse, Hales & Klotz,
"People systematically overlook subtractive changes," Nature 592,
258-261 (2021), https://www.nature.com/articles/s41586-021-03380-y. A
support reply or article is comprehended against working-memory limits:
total cognitive load (intrinsic + extraneous + germane) must stay within
capacity or comprehension degrades — Sweller, cognitive load theory,
summarized at https://thedecisionlab.com/reference-guide/psychology/cognitive-load-theory.
These two findings jointly justify treating removal as a first-class,
not optional, playbook category: subtraction is the lever cognitive-load
theory says lowers extraneous load, and the Nature finding says agents
will not reach for that lever unless a rule cues them to.

## Trigger

Apply this skill when drafting or reviewing a customer-facing reply, a
KCS Resolution field, a canned-response macro, or a playbook rule set,
and need to identify content to remove rather than only content to add.

## Procedure

1. When drafting a customer-facing reply, cut any sentence that restates
   the customer's own problem back to them before the fix (rule 1).
2. When a KCS Resolution field lists more than one working fix for the
   same environment, delete every fix but the one actually verified
   (rule 2).
3. Under time pressure to close a ticket, explicitly ask "what can be
   removed from this reply" as its own step rather than only asking
   "what is missing" (rule 3).
4. When a canned-response macro accumulates a new clause for every edge
   case it has ever handled, review it on a fixed cadence and remove
   clauses that serve fewer than 5% of the macro's use volume (rule 4).
5. When onboarding a new agent to a playbook rule set, cut any rule
   whose condition never fired in the last quarter's ticket volume from
   the mandatory-read set, moving it to reference-only (rule 5).

## Output shape

The same reply, Resolution field, macro, or rule set with the
identified content removed (not merely flagged), and no compensating
addition introduced in its place.

## Rules

- When drafting a customer-facing reply, cut any sentence that restates
  the customer's own problem back to them before the fix — Sweller's
  extraneous-load component is generated by presentation content that
  does not aid schema construction, and a restated problem statement is
  exactly that. Source: https://thedecisionlab.com/reference-guide/psychology/cognitive-load-theory
- When a KCS Resolution field lists more than one working fix for the
  same environment, delete every fix but the one actually verified —
  presenting multiple untested options raises the reader's element
  count with no comprehension benefit, working against the same
  extraneous-load principle. Source: https://education.nsw.gov.au/content/dam/main-education/about-us/educational-data/cese/2017-cognitive-load-theory.pdf
- Under time pressure to close a ticket, explicitly ask "what can be
  removed from this reply" as its own step rather than only asking "what
  is missing" — because additive ideas come to mind quickly and
  subtractive ones require deliberate cognitive effort, a reply drafted
  under pressure will default to addition unless subtraction is cued.
  Source: https://www.nature.com/articles/s41586-021-03380-y
- When a canned-response macro accumulates a new clause for every edge
  case it has ever handled, review it on a fixed cadence and remove
  clauses that serve fewer than 5% of the macro's use volume — macros
  grow additively by default per the Nature finding above, so removal
  needs a scheduled trigger, not an ad hoc one. Source:
  https://ideas.darden.virginia.edu/add-value-through-subtraction
- **REMOVAL**: when onboarding a new agent to a playbook rule set, cut
  any rule whose condition never fired in the last quarter's ticket
  volume from the mandatory-read set (move it to reference-only) — an
  unused rule adds intrinsic load to onboarding comprehension without
  adding decision coverage, per the same working-memory-capacity
  argument. Source: https://thedecisionlab.com/reference-guide/psychology/cognitive-load-theory
