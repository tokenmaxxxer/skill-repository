# Message construction and persuasion

Research trail: Aristotle's rhetorical appeals per Open Rhetoric's
ethos/pathos/logos chapter and StudioBinder's explainer, RDP Marketing's
applied-to-marketing survey, the Construction-Integration comprehension
model per the Medium/Atlantis-Press surveys of Kintsch's and schema-
theory research (working-memory-limited normalization), and Presslink
Media / Hritik Chhangani's minimalist-messaging surveys, all fetched
this session.

## Trigger

Apply this skill when drafting or reviewing persuasive copy: choosing
which rhetorical appeal (ethos/pathos/logos) to lead with, structuring
sentences for a first-time reader, framing against an existing audience
schema, or deciding how many benefit claims a single message should
carry.

## Procedure

1. For price-sensitive or high-consideration buyers, include a logos
   component alongside any emotional appeal (rule 1).
2. With no prior brand relationship, open with an ethos element before
   the pitch's core claim (rule 2).
3. For a message aimed at driving action, apply a pathos element tied
   to the audience's own stated values (rule 3).
4. For a first-time reader, keep sentence/paragraph structure within
   working-memory span rather than stacking multiple claims (rule 4).
5. When the audience already holds a relevant schema, frame the message
   against that schema rather than building from a blank slate
   (rule 5).
6. Once a message carries one core benefit, one CTA, and sufficient
   ethos/logos/pathos support for that claim, cut every additional
   benefit claim from the same message (rule 6).

## Output shape

A copy decision: the applicable rule number(s), the rhetorical
appeal(s) or structural choice applied, and — when rule 6 applies —
which additional claims were cut.

## Rules

1. When a message must move price-sensitive or high-consideration
   buyers, include a logos component (a verifiable statistic, mechanism,
   or comparison) alongside any emotional appeal, since logos appeals to
   the argument's own structure and reasoning, and a message with only
   pathos gives a rational buyer nothing to cite when justifying the
   purchase internally. source:
   https://pressbooks.pub/openrhetoric/chapter/aristotles-rhetorical-appeals/

2. When the buyer has no prior relationship with the brand, choose to
   open the message with an ethos element (a credential, named
   customer, or third-party citation) before the pitch's core claim,
   since ethos is the audience's
   assessment of the speaker's credibility, and a claim from an
   uncredentialed source is discounted regardless of its logical or
   emotional strength. source:
   https://www.studiobinder.com/blog/ethos-pathos-logos/

3. For a message aimed at driving action rather than only recall, apply
   a pathos element that connects to the audience's own stated values
   rather than a generic emotional trigger, since pathos appeals
   specifically to the audience's values and beliefs, and a mismatched
   emotional appeal fails to move a reader who does not share the
   assumed value. source:
   https://rdp.co.uk/being-persuasive-what-we-can-learn-from-aristotle-about-marketing/

4. When drafting copy for a first-time reader, keep the sentence and
   paragraph structure within the reader's working-memory span (roughly
   3-4 connected concepts at a time) rather than stacking multiple
   claims in one sentence, since comprehension research finds the
   construction-integration process is constrained by limited working
   memory and only the most connected concepts retain activation — an
   overloaded sentence loses the reader before the message lands.
   source: https://medium.com/@laurenflynn1211/comprehending-models-of-comprehension-the-construction-integration-ci-model-ad7add92f276

5. When the audience already holds a relevant schema (an existing
   category, prior product experience, a known comparison), frame the
   message against that schema rather than building comprehension from
   a blank slate, since schema-based reading models treat background
   knowledge as doing most of the comprehension work — ignoring the
   audience's schema forces them to build a mental model from raw text
   alone. source: https://www.atlantis-press.com/article/25865797.pdf

6. **REMOVAL**: When a message already carries one core benefit, one
   CTA, and enough ethos/logos/pathos support for that single claim, cut
   every additional benefit claim from the same message rather than
   adding it for completeness — minimalist-messaging practice ties each
   added competing claim directly to decision paralysis and diluted
   attention on the one idea that should land. source:
   https://medium.com/@presslinkmedia/minimalist-marketing-moves-868f44fdc5b1
