Our SaaS admin console's top nav is: Dashboard, Projects, Members, Data Tools,
Settings. "Data Tools" is a dropdown parent that today contains exactly one
item: "CSV Export". It used to also hold "API Sync" and "Webhooks", but both
were retired last quarter and nothing else is planned for that menu on the
roadmap. Analytics show CSV Export is used by about 30% of admins weekly, and
every use costs two clicks (open Data Tools, then click CSV Export).

A teammate argues we should keep the "Data Tools" parent "for consistency with
the other dropdowns, and in case we add tools later."

Decide what to do with the Data Tools menu and CSV Export placement.
