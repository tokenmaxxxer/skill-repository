We're speccing the "Report an issue" form for our desktop support portal
(desktop-first, generous vertical space; the form has 4 fields total). One
field is "Severity" with exactly four mutually exclusive options: Low, Medium,
High, Critical — users are expected to compare the definitions before picking
one, and each option will show a one-line description.

Our design system's default pattern for any enumerated field is a select
dropdown, and the previous version of this form used a dropdown for severity.
The tech lead prefers keeping the dropdown "so the form looks consistent and
compact."

Which control should the Severity field use? Name the control and justify
briefly.
